# Agent status hooks are provisioned into global agent config files

Abundio mirrors each Agent's lifecycle into its status indicator by registering hooks in that Agent's hook system. Hook payloads carry no Pane/PTY identity, so correlation rides on a per-PTY env var read by a small relay; and Agents load hooks only from global or per-project config. Redirecting each Agent's config home per-PTY would detach it from the user's auth and settings, so we instead merge Abundio's hook entries into the **global** agent config (`~/.claude/settings.json`, `~/.codex/hooks.json`, etc.). This means the relay runs for every invocation of that Agent machine-wide, not just inside Abundio — accepted because it is gated behind an opt-in toggle, removes only Abundio's own entries on disable, and the relay exits immediately as a no-op when the Abundio PTY env var is absent.
